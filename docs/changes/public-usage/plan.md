# 路由接入实施计划

[English](plan.en.md) | 简体中文

状态：实施中。范围与语义见[设计](design.md)。

1. **声明与启动**：实现 BSN 声明编译、共同安装、一次性 initial，保留原默认值和显式 host。验证错误位置、失败后重试、多 Router 和真实嵌套页面。
2. **导航与地址**：实现内部地址拆分和 Commands 导航，验证同一页面系统读输入、改组件、导航以及延迟错误处理。
3. **接入闭环**：迁移 quick start、嵌套/窗口示例与独立 consumer；统一推荐入口，补齐常用导出和双语合同/流程说明。运行相关 crate、公开旅程、consumer、格式和静态检查。
4. **动态页面与动画**：保留现有当前输入和显式滚动合同，减少示例重复；验证成熟动画依赖的开始、完成、同步取消后提供可选适配和应用效果示例。若依赖不能满足现有合同，记录具体阻碍，不扩张 Router 职责。
5. **收尾**：按行为风险完成组合验证，核对 feature 依赖、示例和双语文档；迁移长期规则后移除完成计划。按独立交付提交，主代理统一构建和提交。

不交付泛型 RouteQuery、typed-route 宏、业务加载框架或新的生命周期状态机。性能检查聚焦新增使用入口的实际调度成本，不重复既有完整测量。
